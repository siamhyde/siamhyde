# Siam Hyde

I build systems that turn fragmented operational information into structured, usable workflows.

My projects have grown from problems I encountered directly - using AI-assisted development to move from problem discovery and prototypes into working systems with real users and data.

## Projects

### [Hyde Procurement Intelligence](https://github.com/siamhyde/Hyde-Procurement-Intelligence)

**Procurement intelligence system for hospitality businesses.**

Built after experiencing procurement problems first-hand while working as a Kitchen Manager. Hyde turns fragmented supplier purchasing data into structured intelligence for ordering, spend analysis and management decision-support.

**What it demonstrates**

* Operational problem discovery → working product
* Canonical procurement data pipelines
* Behavioural ordering intelligence
* AI-assisted decision support built on governed backend data
* Development from early Google Sheets, Coda and Bubble prototypes into a Supabase/Next.js system
* Real hospitality data and operator testing

**Scale:** 4,700+ transactions · £43k+ supplier spend · 440 active canonical products

**Stack:** PostgreSQL · Supabase · SQL · Next.js · OpenAI API

→ **[View Hyde](https://github.com/siamhyde/Hyde-Procurement-Intelligence)**

### [Job Que](https://github.com/siamhyde/Job-Que)

**Personalised job-discovery and vacancy intelligence system.**

Built to replace fragmented manual job searching with a pipeline that collects, deduplicates, enriches and assesses vacancies against an individual user's profile.

It currently supports multiple users with independent profiles, search strategies and job queues.

**What it demonstrates**

* Automated email and vacancy ingestion
* Data normalisation and deduplication
* Browser-based enrichment
* Profile-specific assessment
* Multi-user system design
* Human-in-the-loop decision workflows

**Scale:** 500+ stored vacancies · 100+ job-alert emails processed · 2 independent user profiles

**Stack:** TypeScript · Next.js · React · PostgreSQL · Supabase · Resend · Playwright

→ **[View Job Que](https://github.com/siamhyde/Job-Que)**

## How I Work

I am particularly interested in the space between **business problems, systems design and AI-enabled implementation**.

I typically start with a messy real-world process, model the underlying problem, build a working system around it and then refine it through actual use.

AI tools, particularly Codex, are integrated throughout that process - from implementation and investigation to testing and specialised agent workflows.
